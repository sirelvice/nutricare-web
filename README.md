# NutriCare (Web) — Nutrition Intelligence & Health Tracking

NutriCare is a modern, privacy-first nutrition-focused healthcare platform.  
It helps users understand and improve their health using evidence-based tools such as **BMI**, **calorie needs**, and **nutrition guidance**, with a foundation designed to support **public-health pilots** and **impact reporting**.

> Web app first (pilot-ready), then mobile app later (scale-ready).

---

## ✨ Key Features (MVP)

### Health Assessments
- BMI calculator with clear interpretation
- (Planned) BMR + daily calorie needs
- (Planned) basic nutrition risk indicators

### Nutrition Guidance
- (Planned) daily targets (calories + macros)
- (Planned) practical meal guidance (local-food friendly)

### Progress Tracking
- (Planned) trends over time (weight/BMI progression)
- (Planned) simple dashboards for users

### Partner / Donor Readiness
- (Planned) impact dashboards (aggregated + anonymized metrics)
- (Planned) exportable reports (CSV/PDF) for pilots
